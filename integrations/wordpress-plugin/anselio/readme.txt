Embed your Anselio AI agent on WordPress as a floating chat bubble or via shortcode.

== Description ==

Connect your Anselio AI agent to any WordPress site. Configure your App URL, Agent ID, and optional widget token from the Anselio dashboard (Deploy → WordPress → Setup).

* Floating bubble on all front-end pages
* Shortcode `[anselio_agent]` for inline chat on specific pages
* Optional height: `[anselio_agent height="720"]`

== Installation ==

1. Upload the plugin zip via Plugins → Add New → Upload Plugin
2. Activate the plugin
3. Go to Settings → Anselio
4. Paste credentials from your Anselio dashboard
5. Visit your site front end to verify the widget

== Frequently Asked Questions ==

= Where do I find my Agent ID? =

In Anselio: open your agent → Deploy tab → WordPress → Setup.

= The widget does not appear =

Ensure App URL and Agent ID are set, your agent is public and active, and the chat widget is enabled in Anselio.
